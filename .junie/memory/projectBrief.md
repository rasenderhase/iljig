# Project Brief: Card Game

## Core Idea
Ein Kartenspiel, das über eine Web-App (Angular) zugänglich ist. Spieler können über ihre eigenen Geräte (QR-Code/PIN) beitreten.

## Goals
- Multi-Device Support: Jeder Spieler nutzt sein eigenes Handy/Gerät.
- Architecture: Client / Server Architektur. Im Server hält eine In-Memory Datanbank die aktiven Spiele.
- Real-time Interaction: Spielzüge müssen sofort bei allen Spielern sichtbar sein.
- Easy Joining: Beitritt über QR-Code oder PIN (ähnlich Kahoot).

## Tech Stack
- **Frontend:** Angular
- **Database:** in Memory
- **Business Logic:** Java 25, Spring Boot
- **Authentication:** keine
